# Cyber-Encryption Lab

Одностраничный криптографический инструмент с живым фоном, звуковыми эффектами и несуморофизным дизайном.

## Демо

Открой `index.html` в браузере.

## Возможности

- Шифрование/дешифрование текста (XOR + Base64)
- Кастомный ключ шифрования
- Живой Canvas-фон с частицами и реакцией на мышь
- Web Audio API звуковые эффекты
- LED-индикатор состояния системы
- Эффект сбоя (очистка во время шифрования)
- Случайный баг при перезагрузке (30%)

## Загрузка на GitHub Pages

1. Создай репозиторий на GitHub
2. Закинь `index.html` в корень
3. В настройках репозитория включи GitHub Pages (ветка `main`, корень `/`)
4. Готово
